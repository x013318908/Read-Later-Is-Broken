# Release Notes v1.1.0

## English

Version 1.1.0 adds light and dark color scheme support to Read Later Is Broken.

What's new:
- Added automatic light and dark mode support for the extension popup.
- Added matching light and dark mode support for the public documentation pages.
- Kept the notebook list area height stable while searching, so the popup layout no longer shifts when result counts change.

## Japanese

バージョン 1.1.0 では、Read Later Is Broken にライトモード / ダークモード対応を追加しました。

更新内容:
- 拡張機能のポップアップが、ブラウザのライトモード / ダークモードに自動で追従するようになりました。
- 公開ドキュメントページも、ライトモード / ダークモードに対応しました。
- 検索中にノートブック一覧の高さが変わらないようにし、検索結果数の変化によるポップアップのレイアウトずれを抑えました。
