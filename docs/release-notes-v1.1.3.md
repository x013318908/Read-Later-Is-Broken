# Release Notes v1.1.3

## English

Version 1.1.3 makes it easier to save the current page to a new notebook and see the results of your actions.

What's new:

- Added "Create and add this page" to create a notebook and save the current page in one action, without entering a name or selecting a notebook. The new notebook appears in the theme list without changing your existing selections.
- Added progress indicators and success/error feedback directly on action buttons.
- If a notebook is created but adding the page fails, "Retry add" retries the page addition without creating another notebook. This is also available after reopening the popup.
- The link to a newly created notebook now displays its name once available. Until then, it remains "Open notebook". The name is updated when the notebook list is refreshed or the popup is reopened.
- Changed the theme notebook list to show checked notebooks first, then sort each group by most recently updated. Newly created notebooks are easier to find, and searching or changing a checkbox does not immediately reorder the list.
- Updated the English and Japanese release screenshots in both light and dark modes.

## Japanese

バージョン1.1.3では、新規ノートブックへのページ追加と、操作結果の確認をしやすくしました。

更新内容:

- 「作成して、このページを追加」を追加しました。名前の入力や一覧での選択なしで、新規ノートブックの作成と現在ページの追加を一度に行えます。作成したノートブックはテーマ別一覧に表示され、既存の選択状態は変わりません。
- ボタン上で処理中・成功・失敗が分かるフィードバックを追加しました。
- ノートブックの作成後にページ追加が失敗した場合、「追加を再試行」で追加だけをやり直せます。別のノートブックは作成しません。ポップアップを開き直した後も再試行できます。
- 新規作成したノートブックへのリンクに、名前が取得できたらその名前を表示するようにしました。それまでは「ノートブックを開く」と表示します。一覧の更新やポップアップの開き直しで名前も更新されます。
- テーマ別一覧を、チェック済みのノートブックを優先し、各グループ内では更新日時の新しい順に並べるようにしました。新規作成したノートブックを見つけやすくなり、検索やチェックの切り替えでは一覧がすぐに並び替わらないようにしています。
- 英語・日本語それぞれのライトモード・ダークモードのリリース用スクリーンショットを更新しました。
