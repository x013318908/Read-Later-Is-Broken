# Release Notes v1.1.2

## English

Version 1.1.2 improves the source-adding workflow and updates the extension materials for the current Gemini Notebook experience.

What's new:
- Added compact direct links beside theme notebooks so each notebook can be opened in a new tab.
- Queued digest and theme add actions in order, keeping the popup controls usable while jobs run in the background.
- Processed theme notebook additions through the background RPC path without opening visible helper tabs.
- Removed the obsolete `notebooklm.google.com` host permission.
- Updated the English and Japanese release screenshots.

## Japanese

バージョン1.1.2では、ソース追加の操作性を改善し、現在のGemini Notebookに合わせて公開用素材を更新しました。

更新内容:
- テーマ別ノートブックの横に1文字幅の直接リンクを追加し、各ノートブックを新しいタブで開けるようにしました。
- ダイジェストとテーマ別の追加操作を順番にキューへ入れ、処理中もポップアップを操作できるようにしました。
- テーマ別ノートブックへの追加をバックグラウンドRPCで処理し、作業用タブを表示しないようにしました。
- 不要になった `notebooklm.google.com` のホスト権限を削除しました。
- 英語・日本語のリリース用スクリーンショットを更新しました。
