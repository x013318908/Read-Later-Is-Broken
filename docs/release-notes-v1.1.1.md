# Release Notes v1.1.1

## English

Version 1.1.1 restores the extension integration after NotebookLM became Gemini Notebook and moved to a new domain.

What's new:
- Updated notebook list, creation, and source-add communication to `notebook.google.com`.
- Kept previously saved `notebooklm.google.com` destinations compatible by normalizing them to the new domain.
- Updated the extension UI and public documentation to use the Gemini Notebook name.

## Japanese

バージョン 1.1.1 では、NotebookLMからGemini Notebookへの名称変更とドメイン移行後も拡張機能を利用できるようにしました。

更新内容:
- ノートブック一覧の取得、作成、ソース追加の通信先を `notebook.google.com` に更新しました。
- 保存済みの `notebooklm.google.com` の追加先を新ドメインへ正規化し、引き続き利用できるようにしました。
- 拡張機能のUIと公開ドキュメントの表記をGemini Notebookに更新しました。
